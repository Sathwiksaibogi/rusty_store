# Rusty Store Inventory Management System

A secure, high-performance command-line retail inventory management engine built entirely from scratch using Rust.

## Features
- **Security Guard:** Layered user authentication via an isolated credentials module.
- **Robust Inventory CRUD:** Fail-safe mechanisms to register, adjust, or liquidate stock assets without risk of data overwrite.
- **Transactional Ledger Matrix:** Automated point-of-sale volume verification coupled with acquisition cost/revenue tracking loops.
- **Tabular Reporting Systems:** Space-aligned text tables generating clear business metrics and accurate transactional records.

## How to Build and Run
1. Ensure you have the Rust toolchain installed (`cargo --version`).
2. Clone this repository to your machine.
3. Open your terminal inside the root directory and execute:
   ```bash
   cargo run
